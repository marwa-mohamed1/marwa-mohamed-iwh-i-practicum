# Marwa Mohamed - Integrating With HubSpot I Practicum

## Custom Object List View
[View My Pets in HubSpot](https://app-eu1.hubspot.com/contacts/147315755/objects/2-195010477/views/all/list)

## Features
- ✅ Create new pets via web form
- ✅ Display all pets in a beautiful responsive table
- ✅ Modern CSS design with gradients and animations
- ✅ Full integration with HubSpot CRM API
- ✅ Node.js, Express, Pug templating

## Setup
1. Clone repository
2. Run `npm install`
3. Create `.env` file with HubSpot credentials
4. Run `node index.js`
5. Visit `http://localhost:3000`
